# Favorit Parts — Test Task

## Запуск проекта

1. Установить зависимости:

```bash
npm install
```

2. Создать файл `.env.local` в корне проекта и добавить переменную:

```env
VITE_API_KEY=00000000-0000-0000-0000-000000000001
```

3. Запустить приложение:

```bash
npm run dev
```

После запуска открыть адрес, указанный в терминале.
